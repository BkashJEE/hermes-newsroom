# Brand assets

`icon.svg` is the source. Everything else is rendered from it, so change the SVG
and re-render rather than editing a PNG.

| File                 | Use                                        |
| -------------------- | ------------------------------------------ |
| `icon.svg`           | source mark, 1024px artboard               |
| `icon.png`           | 1024px, packaging                          |
| `icon-256.png`       | desktop and app listings                   |
| `icon-64.png`        | small UI                                   |
| `social-preview.png` | 1280x640, GitHub Settings > Social preview |

Product screenshots live in `docs/images/` and are captured from the bundled
demo data, never from a real feed, so they carry no one's watchlists or records.
