# Newsroom section audit

The public feed currently samples the first 80 Hacker News top-story IDs and up to 15 official Hermes GitHub releases, retaining items within the configured feed window. It is not a comprehensive news archive or a social virality feed. Titles determine coarse topic tags and heuristic relevance/evidence scores; those are not independent editorial verification.

| Section           | Current behavior and audit changes                                                                                                                                                                                                                                                                                              |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Front Page        | Lead, actions, intelligence drawer and saved state. Preferred story-type slots fall back to other available stories without duplicating the lead. Missing images no longer reserve a blank half-card.                                                                                                                           |
| Live Wire         | Newest first; all active filters apply. More than 25 stories can be expanded with Show all. Empty filtered views now explain the result.                                                                                                                                                                                        |
| Hermes Daily      | Full-width flashcards, four-page newspaper view and browser Print / Save PDF. Local excerpts are labelled separately from requested Hermes writing.                                                                                                                                                                             |
| Personal Daily    | Explicit local opt-in and excerpt disclosure. This audit does not generate or transmit personal records. See personal-daily.md.                                                                                                                                                                                                 |
| Weekly Chronicle  | A Hermes-only weekly grid of official releases, merged core changes, community releases and repository activity from the past seven days. The weekly desk selector distinguishes shipped releases, inside-agent updates and community activity. Search/source/watchlist filters apply; the header labels the fixed date window. |
| Built With Hermes | Public project catalog ranked by lifetime stars/forks or update time; official release stories separately filtered across 30 days. The catalog explains its independent scope.                                                                                                                                                  |
| Trend Radar       | Live sources lack repeated engagement samples. Rank topics by story count and show coverage shares, not zero growth presented as measured. Synthetic scenarios retain their example momentum.                                                                                                                                   |
| Content Desk      | Search saved draft titles/text, edit/save/copy/remove locally. Recommendations honor feed filters; these filters do not hide older draft records.                                                                                                                                                                               |
| Archive           | Search/filter saved and dismissed snapshots across all retained dates; restore still works. This is a local collection, not all historical news.                                                                                                                                                                                |

The Hermes panel shares section selection logic with the workspace. It lists its evidence count and disables submission for an empty selection. Requests are limited to 40 current server-resolved stories in the selected order. The separate project/weekly activity catalogs, local draft text and older snapshots absent from the feed are explicitly excluded. This is editorial assistance, not autonomous control of every tab. The gateway tool-isolation limitation in providers.md remains unresolved; no live model request is needed for the UI audit or tests.

Remaining: social-source connectors and engagement history; richer topic classification; a complete historical feed store; personal newspaper generation/visual review using authorized records; and the Jev demonstration described in jev-live-desk.md.

Section headings and their action rows now remain below the measured global header while scrolling. Weekly, community builds, Daily and Live Wire have desktop/mobile overlap checks; Personal Daily pins its edition controls.

Weekly Chronicle separates shipped releases, changes inside Hermes and community reports. Cards show two bounded source bullets, with details on demand, six initial recaps per category and one stable-release recap per project. Prereleases stay separate. Unconfirmed repository pushes are collapsed under Activity to watch; duplicate activity for projects with sampled releases is removed.

Personal Daily now reflows saved and newly generated editions into four A4 pages, preserving the original saved edition and source records. Layout validation uses synthetic records only.
